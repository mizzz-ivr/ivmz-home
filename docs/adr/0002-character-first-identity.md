# ADR 0002 — Character-first identity

Status: Accepted — 2026-08-25

## Context

The first Purple Signal concept interpreted orbit/particle notes as a literal cosmic theme. The actual identity anchor is the original character used in the GitHub avatar.

## Decision

- Make the canonical character the primary visual anchor.
- Purple Signal is a supporting graphic language, not a planet/space theme.
- Remove planet/orbit/starfield motifs as primary imagery.
- Use depth through frames, workbench/editor fragments, project surfaces and typography.
- New character art must be based on an approved source image to avoid identity drift.

## Consequences

The site should feel recognizably connected to the GitHub profile and creator identity while retaining the requested dimensional scroll experience.
