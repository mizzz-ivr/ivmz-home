# トップページの FAQ チャット

トップページの「よくある質問」と、右下の「質問する」チャットです。

## 仕組み

1. **FAQ（常に動きます）**: 質問の候補ボタン、または入力した文章のキーワードで、あらかじめ用意した回答を返します。内容は `src/lib/faq-content.ts` にあります（FAQ の一覧とチャットが同じデータです）。入力内容はブラウザの中だけで処理され、送信も保存もされません。
2. **AI 回答（任意）**: FAQ にない自由入力だけ、AI に聞きます。設定していなければ、FAQ にない質問は「うまくお答えできませんでした。お問い合わせフォームへ」と案内します。

AI は **Cloudflare Workers AI の無料枠**（1日 10,000 ニューロン）を使います。1回の質問は約 50〜100 ニューロンなので、1日に 100 件前後まで無料です。

## 守っていること

- 回答はサイトの FAQ の内容だけを根拠にし、わからないことは推測せずフォームへ案内するよう指示しています（料金・納期・予定などは答えません）。
- 利用者の発言の中の指示（「ルールを無視して」など）には従わない指示を入れています。回答はプレーンテキストで表示し、リンクや HTML は出しません。
- 質問は 120 文字までで、AI に送るのは「いま入力した1件」だけです（過去のやり取りは送りません。FAQ で答えた内容も外へ出ません）。
- 同じ人は 10 分に 8 回まで、全体で 1 日 80 回までに制限しています（サーバーごとの目安です）。
- ブラウザからの呼び出しだけを受け付けます（サイトの Origin のみ）。
- 質問の内容は **当サイトでは保存もログ出力もしません**。上限に達した、エラーになった、タイムアウトした場合は、自動で FAQ の回答に戻ります。
- プライバシーポリシーに、AI 回答のしくみと Cloudflare Workers AI の利用を記載しています。

## AI 回答を有効にする手順（あなたの作業）

1. Cloudflare のダッシュボードで **Account ID** を確認します（右側のサイドバー、または Workers & Pages の画面）。
2. 「My Profile」→「API Tokens」→「Create Token」で、**Workers AI** の権限（Read）を持つトークンを作ります。
3. Netlify の環境変数（**Production**）に、次の2つを入れます。スコープは **Functions と Runtime**、値は「秘密」にします。
   - `CHAT_LLM_ACCOUNT_ID` = Account ID
   - `CHAT_LLM_API_TOKEN` = 作ったトークン
4. 再デプロイすると（ページの再生成を待たずに、チャットを開いたときに状態を確認します）、チャットの注意書きが「FAQにない自由入力はAIに送ります」に変わり、AI 回答が有効になります。

トークンは秘密情報です。チャットや Git には貼らないでください。

- 止めたいとき: `CHAT_LLM=off` を入れて再デプロイ（または 2 つの変数を消す）。
- モデル: 既定は、使えるものを順に試します（`@cf/zai-org/glm-4.7-flash` → `@cf/google/gemma-4-26b-a4b-it` → `@cf/meta/llama-3.1-8b-instruct`）。Cloudflare は古いモデルを定期的に終了するため、1つ目が使えなくなっても次に切り替わります。固定したいときは `CHAT_LLM_MODEL` にモデル ID を入れます。エラーはステータスだけが Netlify の関数ログ（`CHAT_LLM_FAILED`）に出ます（質問の内容は出ません）。
- 有料プランの Workers を契約していると、無料枠を超えた分は課金されます。無料プランのままなら、上限に達するとエラーになるだけで、課金はされません。
