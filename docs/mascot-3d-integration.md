# 立体マスコットの実装境界とGLBアセット受け入れ条件

関連 Epic #99 / 3Dマスコット #103 / 既存2Dペット #73・Draft PR #78 / 性能 #106。

## 今回の段階（描画前のロジック検証）

`src/lib/mascot-locomotion.ts` に、ポインタとの**画面上の距離**に応じて `idle` / `walk` / `run` を決める純粋関数を定義。走行への移行と解除にはヒステリシスを持たせる。閾値は初期案でありGLBモデルの歩幅・表示スケール・追従速度に合わせて調整すること。

**このモジュールはアニメーションを再生せず、3Dモデルはまだ表示しない。** 次段階で実GLBを受け取り、WebGL対応のローダー・Mixer・クロスフェードに接続する。

## 追従移動の初期実装（モデル搭載前）

`src/lib/mascot-follow.ts` は、3Dモデルの描画方式に依存しない**時間ベースの位置・向きの移動**を扱う。

- `stepMascotFollow(current, target, elapsedSeconds, viewport)` を1フレームごとに呼ぶ。返り値の`position`はレンダラーのCanvas上の移動、`facingRad`はモデルの向きへ渡す。画面座標Y軸は下向きのためGLBのup-axisやカメラ配置によって回転変換を行う。
- `locomotion`は既存`resolveMascotLocomotion`から決定。初期値：walk 140 CSS px/s、run 360 CSS px/s、回転最大540°/s、追従停止の距離28px。**実モデルとブラウザでの見た目を確認するまで暫定値**。
- 毎フレームの`elapsedSeconds`を最大0.05秒に制限。タブを離れて戻った直後の大移動を防ぐ。`viewport.padding`で画面端から距離をとり、画面外ターゲットを境界へ制限する。
- 無効座標/非有限数値/ゼロ以下のdeltaは状態を変えない。純粋関数なのでベース描画・React state・ローカルストレージ・WebGL APIには依存しない。
- 既存`PointerPet`のmove loopへ直接追加するのではなく、**3Dレンダラーの専用制御ループ**から呼び出し、同一設定を利用して2Dペットと排他にする。両方の追従を常時起動しない。
- モーションステート`walk/run/idle`は移動に対応するClipへマップするが、実ボーン・歩幅の運動は**承認済みGLBのAnimationClipが担う**。この座標処理だけでは「歩行アニメーション実装済み」ではない。

テスト：walk/runの速度差、追従停止と停止距離、`-π/π`境界の最短回転、フレーム間隔上限、viewport端、巨大/壊れた入力、resize後の位置補正。

## アセット受け入れ条件（事前検収）

- GitHubアバターのオリジナルキャラクターと顔/紫目/配色/雰囲気が一致し、本人または権利者の使用・改変・配信許諾が確認できること。
- GLB（glTF 2.0）で、立体メッシュと適切なボーン、`idle` / `walk` / `run` の3アニメーションクリップを含むこと。
- クリップはループ境界でポーズが破綻しないこと。速度の違いが足運びと身体の傾きとして観察できること。必要に応じ `turn` を追加。
- 原点、縮尺、床に対する接地位置、前方向、テクスチャ・透明背景・圧縮方法、使用モデルの最適化情報を仕様に記載。
- GLBデータに個人情報・無断第三者の作品・解析用URL等を埋め込まない。
- デフォルト表示では無音。低解像度/モバイルは無効化し、ユーザーのON/OFF設定とreduced-motionを尊重する。

## 予定するレンダリング境界

1. WebGLサポート・モデルサイズ・バンドル増分をSpikeで計測（Three/R3F等はこの時点で選定）。
2. 追従targetとキャラ位置を独立管理し、Canvas/Raf内の移動にReact毎フレーム再レンダリングを利用しない。
3. 上記state解決関数 → 実GLB `idle/walk/run` のAnimationClipsへクロスフェード。移動速度と足の運動を合わせる。
4. Canvasは `pointer-events:none`。MainコンテンツやCTA、Contact入力はDOMで常に使用可能。
5. WebGLが失敗/コンテキスト消失/タブ非表示の場合、描画ループを停止、静止2Dもしくは非表示にフォールバック。タッチ端末とreduced-motionでは強制的に追従しない。
6. 既存2Dペットを重複描画させず、置換/非表示条件・ストレージ設定をレビュー。

## テスト（今回 / 次段階）

- 今回：停止境界（28px）、歩行開始（48px）、走行開始（180px）/解除（120px）、NaN/Infinity/負数、ヒステリシス。
- 次段階：FPS・GPU負荷・モデルサイズ・LCP/INP/CLS、表示切替、画面端、マウス高速移動、リサイズ、アンマウント、タブ非表示、Canvas不可・context lost。
- モデルが未提供の状態で「実3Dの完成」とは判断しない。Main/Productionの変更は承認後。
