# 問い合わせフォームのボット対策（Cloudflare Turnstile）

無料の Cloudflare Turnstile を、問い合わせフォームの**最終送信**に追加できます。通常は「私はロボットではありません」のチェックも
不要で、人間らしさをブラウザの挙動から自動判定します。

- 未設定のままでも、サイトは今までどおり動きます（ハニーポット・同一オリジン検査・レート制限は常に有効）。
- 設定すると、確認画面に Turnstile が表示され、**認証が済むまで「送信する」が押せません**。
- サーバー側でも検証し、トークンが無い・不正・再利用・検証に失敗した場合は `403 captcha_failed` で拒否します（検証できない場合も拒否＝安全側）。
- 入力内容のエラー（422）ではトークンを消費しません。送信のたびに新しい認証をやり直します。

## 設定手順

1. Cloudflare のダッシュボード → **Turnstile** → 「ウィジェットを追加」。
   - ドメイン: `ivmz.ivrm.jp`（プレビューで試す場合は `deploy-preview-*.netlify.app` を追加するか、テスト用キーを使います）。
   - モード: **Managed**（おすすめ）。
2. 作成後に表示される **サイトキー**と**シークレットキー**を控えます。
3. Netlify の環境変数（**Production** のみ）に追加します。
   | 変数名 | 値 | Secret |
   | --- | --- | --- |
   | `TURNSTILE_SITE_KEY` | サイトキー（公開してよい値） | いいえ（スコープに **Builds** を含める） |
   | `TURNSTILE_SECRET_KEY` | シークレットキー | **はい**（Production のみ。dev には入れない） |
4. 再デプロイします（Deploys → Trigger deploy → Deploy site）。

## 動作確認

- `/contact` で入力 →「内容を確認する」→ 確認画面に Turnstile が出て、通ると「送信する」が押せるようになる。
- シークレットだけ入れてサイトキーを入れない（またはその逆）と、確認画面で送信できなくなります。必ず両方入れてください。

## 添付ファイルのアップロードについて

添付のアップロード API は、現時点では Turnstile の対象外です。アプリ側の IP 別レート制限（1分あたり 20 回）と、
添付機能のオン/オフ（CMS）で保護しています。濫用が見られたら、アップロードにも Turnstile を適用できます。

## 無効にするには

`TURNSTILE_SECRET_KEY` と `TURNSTILE_SITE_KEY` を削除して再デプロイします。
